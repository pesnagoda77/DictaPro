# UI/UX-бенчмарк: URecorder (voicerecorder.audiorecorder.voice v1.3.6.1)

Разобрано по 11 скриншотам (16.09.2026). Не конкурент: офлайн-расшифровки нет. Берём как эталон эргономики записи.

## Функции (что видно на экранах)
- Запись: качество (High CD), формат M4A, источник (основной/Bluetooth-микрофон), частота 44,1 кГц, битрейт 128 кбит/с, моно/стерео.
- Сценарии: Standard / Live text / Встречи и лекции / Музыка без обработки — карточки с пояснениями.
- Продвинутое: авто-запись при запуске, быстрая запись без открытия, уровень входа (+12 дБ), АРУ, шумодав, эхоподавление, пауза на звонке, не гасить экран.
- Библиотека: теги (Все/Без тега), поиск, сортировка, плейлисты, метаданные, меню (переименовать, тег, шаринг ссылкой, детали, бэкап в Drive, удалить, сжать, голос, шумодав, AI-модель, фоновая музыка).
- Прочее: видимый путь хранения, управление записью из уведомления, темы, язык, подписка, реклама с «убрать».

## Берём (для DictaPro)
1. Одна главная = список записей; большая кнопка записи снизу по центру; иконки список/настройки/меню.
2. Сценарии записи крупными плитками с человеческим пояснением (Диктовка / Лекция / Встреча / Шумно).
3. Настройки группами-вкладками (Основные / Расшифровка / Хранение) вместо простыни.
4. Видимый путь хранения + папки/теги.
5. Бэкап/экспорт отдельным понятным пунктом.

## Не берём
1. Криптические подписи («Audio source: Main» и т.п.).
2. Обилие тумблеров верхнего уровня; шумодав не рекламируем (по нашим данным вредит ASR).
3. Реклама и «убрать рекламу» — у нас не будет.
4. «Live text» → у нас «Расшифровка».
5. Иконка премиума в общем ряду иконок.

## Наше отличие
Офлайн-расшифровка на устройстве, приватность, русский язык — этого у него нет.
