# Дизайн-система DictaPro (v1, 24.09.2026)

Источник: макет `docs/design/dicta_design_v1.png` (+ `dicta_design_v1.html`).
Тон: **«тихий инструмент-ноутбук»** — глубокая сине-графитовая база, мята как рабочий акцент,
тёплый красный только для главного действия. Никакого «вечера в рабочем посёлке».

## 1. Цвета (токены)

| Токен | Значение | Где |
|---|---|---|
| `bg0` | `#111A24` | нижний фон, «дно» экрана |
| `bg1` | `#182532` | основной фон (градиент сверху) |
| `bg2` | `#1F2E3D` | поля ввода, непрозрачные подложки |
| `surface` | `rgba(255,255,255,.055)` | карточки (градиент к `.03`) |
| `line` | `rgba(255,255,255,.09)` | границы, разделители |
| `line2` | `rgba(255,255,255,.16)` | границы активных/важных блоков |
| `ink` | `#EAF2F5` | основной текст |
| `ink2` | `rgba(234,242,245,.66)` | вторичный текст, подписи |
| `ink3` | `rgba(234,242,245,.42)` | служебное (мета, статус-бар) |
| `mint` | `#8FE3D2` | акцент: активные состояния, статусы, ссылки |
| `mint2` | `#4FB3A5` | тёмная мята (градиенты, прогресс) |
| `red` | `#FF6B6B` | **только** главное действие (запись, покупка) |
| `gold` | `#FFD166` | бейдж «лучшая цена за год» |

Атмосфера фона: два мягких радиальных свечения (мята сверху, тёплый красный снизу-справа) поверх
градиента `bg1 → bg0` + **шум 3px / 5%** — вместо плоского цвета.

Контраст: `ink` на `bg1` ≈ 13:1; `ink2` ≈ 6,5:1; `mint` на `bg1` ≈ 8:1 (WCAG AA соблюдён).

## 2. Типографика

- **UI/текст:** `Onest` (кириллица, современный геометрик). Веса: 400 / 500 / 600 / 700 / 800.
- **Числа, таймер, длительности, мета:** `JetBrains Mono` 600/700 (ровные цифры).
- Шкала: H1 20/800 · H2 16/700 · body 13/400 · small 11/500 · mono-мета 10.5.
- Заголовки — короткие, без капса и разрядки; акцент в заголовке — мятой, а не размером.

## 3. Форма и глубина

- Радиусы: `10` (мелкое), `14` (карточки), `20` (крупные блоки), `26` (hero), `99` (чипы/пилюли).
- Тени: одна мягкая на «полотно» — `0 18px 44px rgba(0,0,0,.45)`; карточки без собственных теней.
- Градиенты: только на акцентных поверхностях (мятная рамка hero, красная кнопка, прогресс).

## 4. Компоненты

| Компонент | Правила |
|---|---|
| **Карточка записи** | название 13.5/700 → мета mono 11/ink3 → статус-тег. Варианты: «расшифровано», «в очереди», «без текста» |
| **Тег статуса** | мята (готово) / серый (ожидание, `ink2`) / красный (ошибка, `#FFB3B3`) |
| **Плашка прогресса** | мятная рамка 24% + строка «идёт N мин · готово K кусков · %» + полоса 5px |
| **Сетка действий** | 4 колонки, ячейка: иконка+подпись; порядок — по частоте (В текст, Итоги, Диалог, Термины, Теги, Экспорт, Отправить, Копировать, Переименовать, Продолжить, Сводка дня, Удалить) |
| **Hero-запись** | карточка с мятной рамкой: подпись «на устройстве · модель внутри» → круглая красная кнопка 88px → таймер mono 25px → подпись |
| **Чипы фильтров** | «Все / Сегодня / В очереди»: активный — мята на тёмном тексте |
| **Редактор диалога** | реплика: мятная линия слева, «ГОВОРЯЩИЙ N» 10.5 мятой, текст 12.5; инструменты рядом: Поменять говорящего · Разделить · Объединить |
| **Итоги** | блоки «О чём договорились / Задачи (чекбоксы) / Цифры и даты»; заголовки мятой 12/700 |
| **Подписка** | переключатель Месяц/Год (актив — мята), карточки ступеней, бейдж gold, красная CTA, ссылки мятой |

## 5. Обязательные правила подачи

1. **Приватность — всегда в трёх местах, но не в лицо:** подзаголовок приложения («Не покидая телефон»),
   строка на главной («на устройстве · модель внутри»), футер/подвал экрана.
2. **Красный = только главное действие** (запись, покупка). Никаких «красных акцентов» в мелочах.
3. **Эмодзи не используем** — только линейные SVG-иконки.
4. Никаких плоских однотонных фонов: свечения + шум.
5. Цифры — только mono (таймеры, длительности, объёмы, цены).

## 6. Что внедрить в приложении

- `lib/theme/app_theme.dart` — заменить на эти токены (тёмная тема — основная; светлую не ломаем,
  собрать из тех же семантических токенов).
- `home_page.dart` — карточка записи + сетка действий + плашка прогресса по этому макету.
- `summary_page.dart` — блоки итогов с чекбоксами задач.
- `player_page.dart` — «диалог»: реплики по говорящим + инструменты.
- `settings_page.dart`, `dialogue_editor.dart`, `operation_progress.dart` — привести к токенам.
- Заголовок сплэша и надписи — в новом стиле (слоган «Не покидая телефон» сохранить).
