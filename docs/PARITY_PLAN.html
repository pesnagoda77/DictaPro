Один код (Flutter), две сборки. «Идентичность» = закрыть платформенные различия и один раз прогнать обе сборки по одному чек-листу.

Общая часть (один раз на обе платформы)

СДЕЛАНО
  • локализация ru/en/de/it (060)
  • онлайн-итоги через наш воркер, ключ из секрета (064)
  • автопроверка секретов + analyze перед сборкой
  • iOS: фон, нерушимый экран, читаемая карточка восстановления
ОСТАЛОСЬ ПО КОДУ
  • экран «Подписка» (065) — сейчас купить негде
  • проверка обоих языков на всех экранах
ОСТАЛОСЬ ПО КОНСОЛЯМ (владелец)
  • Play: подписки sub_diary / sub_assistant / sub_unlimited + пакеты pack_*
  • Play: лицензионные тестеры + отправка релиза закрытого теста
  • App Store Connect: приложение, те же товары, Sandbox-аккаунт
