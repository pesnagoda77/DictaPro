## Дизайн-система (обязательно)

Токены — в `lib/theme/app_theme.dart` (`AppColors`, `DictaTokens.of(context)`), готовые элементы —
в `lib/widgets/dicta_ui.dart` (`DictaCard`, `DictaStatusTag`, `DictaChip`, `DictaMicButton`, `DictaProgressPlate`,
`DictaSectionTitle`, `DictaBottomNav`, `DictaBrand`).

Правила:
1. **Цвета — только из токенов.** Никаких `Colors.white54`, `Colors.red`, `withOpacity` в новом коде.
   Акцент — мята (`tk.mint`), красный (`tk.red`) — **только** главное действие (запись/покупка).
2. **Цифры** (таймеры, длительности, цены, объёмы) — моно-шрифт: `tk.mono(12, FontWeight.w600)` или `fontFamily: 'JetBrains Mono'`.
3. Радиусы: мелкое 10, карточки 14, крупное 20, hero 20–26, чипы 99. Границы — `tk.line`, важное — `tk.line2`.
4. **Без эмодзи** — только линейные иконки Material (Rounded/Outlined, 17–20 px).
5. Фон экрана — `DictaBackground` (градиент + свечения), плоских однотонных фонов не делать.
6. Тёмная тема — основная; светлая должна собираться из тех же токенов (проверяй, что не «прибито» гвоздями).
7. Состояния: пусто / загрузка / ошибка / недоступно — везде, где есть данные.
8. Логику НЕ менять: покупки, ключи, доступ к файлам, сервисы. Только представление и тексты (тексты — через существующие `AppStrings`.
   Новые строки можно добавлять в `lib/app_strings.dart` **только аддитивно** (ключ + 4 языка: ru/en/de/it).
