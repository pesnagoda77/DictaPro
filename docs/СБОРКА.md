# Сборка DictaPro

Референс: релизный процесс DictaPro. Качество движка (модель / нарезка / VAD)
в релизных правках НЕ трогаем — это отдельный трек.

## Версия

Версия живёт в двух местах, менять вместе:

- `pubspec.yaml` → `version: 1.0.0+49`
- `android/app/build.gradle` → `versionCode 49` / `versionName "1.49"`

Без указания версию не менять.

## Модель GigaAM v3 — обязательный шаг перед сборкой (task 019)

Модель (~222 МБ) в git не коммитится. Скачивается один раз:

```bash
python3 tools/fetch_model.py        # Windows: python tools\fetch_model.py
```

Скрипт кладёт 5 файлов (`encoder.int8.onnx`, `decoder.onnx`, `joiner.onnx`,
`tokens.txt`, `silero_vad.onnx`) в `assets/models/gigaam_v3_punct/` и
в install-time asset pack `android/gigaam_pack/...` (для Play). Проверяет
размеры, докачивает при обрыве.

### APK (прямая раздача)

```bash
python3 tools/prepare_apk_build.py                     # модель → flutter-ассеты
flutter build apk --release --split-per-abi
```

### AAB (Google Play)

Модель идёт через asset pack автоматически. Перед сборкой убедиться, что
модель НЕ лежит во flutter-ассетах (иначе base-часть >200 МБ, отказ Play):

```bash
python3 tools/prepare_apk_build.py --clean
flutter build appbundle --release
```

### Проверка результата (обязательна)

```bash
unzip -l build/app/outputs/flutter-apk/app-arm64-v8a-release.apk | grep gigaam
# ожидание: 5 файлов assets/models/gigaam_v3_punct/* — модель в сборке

unzip -l build/app/outputs/flutter-apk/app-arm64-v8a-release.apk | grep -i vosk
# ожидание: ПУСТО — старый движок удалён

python3 docs/tools/check_16k.py build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
# ожидание: «Все библиотеки совместимы с 16 КБ.»

python3 docs/tools/check_16k.py build/app/outputs/bundle/release/app-release.aab
# то же для AAB

ls -la build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
# ожидание: ≈ 260–280 МБ (99 МБ приложение − старый движок + 222 МБ модель).
# Если ~100 МБ — модель НЕ попала в сборку, расшифровки не будет.
```

Функциональная проверка: удалить приложение с телефона, поставить APK,
выключить интернет, записать 1–2 минуты → расшифровка работает
(при первом запуске — один раз «Подготовка модели» с прогрессом,
копирование локальное, без сети).

## Релизная сборка (по шагам)

### 0. Бэкап рабочей версии — обязательно

Требование Славана: перед сборкой релиза — бэкап, никогда не терять
последнюю рабочую версию.

```powershell
powershell -ExecutionPolicy Bypass -File tools\backup_release.ps1
```

Скрипт кладёт исходники + git-состояние + собранные APK/AAB в
`D:\Projects\Backups\dictapro_YYYY-MM-DD_<версия>` и пишет строку в
`D:\Projects\Backups\backups_registry.csv`.

### 1. Анализ

```
dart analyze lib
```

Допуск: 0 ошибок.

### 2. APK сплит по ABI

```
python3 tools/prepare_apk_build.py
flutter build apk --release --split-per-abi
python3 tools/prepare_apk_build.py --clean
```

Выход: `build/app/outputs/flutter-apk/`:

- `app-arm64-v8a-release.apk` — **основная, её ставим пользователям**
- `app-armeabi-v7a-release.apk`
- `app-x86_64-release.apk`
- `app-x86-release.apk` (эмуляторы)

Fat-APK без сплита ~202 МБ (4 набора нативных библиотек внутри).
Цель arm64-сплита: **≈ 260–280 МБ** (модель внутри).

sherpa_onnx попадает в сплиты автоматически: плагин шипит per-ABI `.so`
внутри AAR, Flutter раскладывает их по сплитам. Отдельная конфигурация
в `build.gradle` не нужна — `--split-per-abi` делает всё сам (ручной
блок `splits {}` не добавлять, конфликтует).

Проверка, что в arm64-сплите только arm64-нативки:

```bash
unzip -l build/app/outputs/flutter-apk/app-arm64-v8a-release.apk | grep "\.so"
# ожидание: только lib/arm64-v8a/*.so, включая libsherpa-onnx-c-api.so;
# libvosk.so НЕТ (движок удалён в task 019);
# x86/x86_64/armeabi-путей быть не должно
```

### 3. AAB для Google Play

```
flutter build appbundle --release
```

Выход: `build/app/outputs/bundle/release/app-release.aab`.

Для Google Play AAB — обязательный формат: Play сам нарежет bundle
по ABI/языкам/плотности через bundletool. Модель — в install-time
asset pack `gigaam_pack`: ставится одной операцией с приложением,
базовая часть укладывается в лимит 200 МБ. Размер AAB фиксировать
в журнале релиза рядом с размерами APK-сплитов.

### 4. Подпись

Релиз подписан keystore'ом, параметры — в `android/key.properties`
(файл локальный, в git не коммитится):

```
storeFile=...
storePassword=...
keyAlias=...
keyPassword=...
```

`minifyEnabled true` + `shrinkResources true` уже включены в release-сборке.

## Запреты

- Не менять модель / нарезку / VAD.
- Не менять версию без указания.
- Не качать модели/ассеты при сборке; распознавание — без сети.
- Не коммитить модель в git (222 МБ, скачивание через tools/fetch_model.py).
- Не собирать AAB, пока модель лежит во flutter-ассетах (`--clean` обязателен).
