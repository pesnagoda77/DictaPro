# Скриншоты для сторов — план съёмки ДиктаПро

## Google Play (Android)
Требование: минимум 2, рекомендуется 6–8. Размер: 1080×1920 (или больше, соотношение не жёсткое).
Формат: PNG/JPEG без рамки устройства (можно с рамкой через Device Art Generator).

### Кадры (снимать на эмуляторе ru + en локали)
1. **Главный с записью** — список записей + большая кнопка записи. Подпись: «Записывайте одним касанием»
2. **Расшифровка в процессе** — диалог прогресса «Кусок 3 из 12 · 25%». Подпись: «Часы аудио — минуты текста»
3. **Готовый текст** — экран транскрипта с таймкодами. Подпись: «Текст с таймкодами»
4. **Итоги/саммари** — экран итогов записи. Подпись: «ИИ-итоги по подписке»
5. **Поиск** — поисковая строка с результатами. Подпись: «Поиск по всем записям»
6. **Настройки приватности** — блок «Всё хранится на устройстве». Подпись: «Файлы не покидают телефон»

## App Store (iOS)
Обязательно: 6.7" (1290×2796) и 6.5" (1242×2688), минимум 3 каждый. Без рамок устройства.

Те же 6 кадров (локаль en основная, ru дублирует).

## Процесс
1. Запустить эмулятор (Pixel 6 API 34, 1080×2400 — кадрировать до 1080×1920)
2. Установить APK релизной сборки
3. Создать 3–4 демо-записи с расшифровками (RU локаль)
4. Снимать через adb exec-out screencap
5. Повторить с локалью en-US (изменить язык эмулятора)
6. iOS: запустить на симуляторе iPhone 15 Pro Max, cmd+S скриншоты (сразу 1290×2796), плюс iPhone 11 Pro Max режим для 1242×2688

## Подписи (captions) на скриншотах
Не обязательны, но повышают конверсию. Делать наложением текста сверху/снизу кадра (не занимать центр), шрифт системный, кегль крупный.
