Дикта: что нужно от владельца — пошагово

Два блока: сначала Google Play (он держит релиз Android), затем App Store Connect (для iPhone). После каждого — напиши «готово», я проверю и продолжу.

Блок A. Google Play (сейчас)

  1. Открой Play Console под аккаунтом Albatech Group → приложение ДиктаПро.
  2. Монетизация → Продукты → Подписки → «Создать подписку» — три штуки:
ID подпискиНазваниеПлан «месяц»План «год»
sub_diaryДневник490 ₽4 900 ₽
sub_assistantАссистент990 ₽9 900 ₽
sub_unlimitedБезлимит1 990 ₽17 910 ₽
  1. В каждой: «Создать базовый план» → Месячный → цена → Сохранить; затем добавить Годовой план. Итог: у каждой подписки два активных плана.
  2. Монетизация → Продукты → Товары (разовые) — четыре пакета: pack_1h 29 ₽ · pack_10h 249 ₽ · pack_50h 990 ₽ · pack_200h 3 490 ₽.
  3. Настройки → Лицензионное тестирование: убедись, что там есть твой Google-аккаунт.
  4. Тестирование и выпуск → Тестирование → Закрытое тестирование → у черновика релиза нажми «Отправить на проверку».
  5. Напиши мне «готово» — я проверю через API, что товары и релиз поднялись, и передам сборку тестерам.

Блок B. App Store Connect (после A или параллельно)

  1. appstoreconnect.apple.com → Мои приложения → «+» → Новое приложение: платформа iOS, имя «ДиктаПро», язык русский, bundle ID com.dictapro.app (если его нет в списке — создать Bundle ID в developer.apple.com), SKU — любой, например dictapro001.
  2. В приложении → Подписки: группа «Дикта» → три подписки с ID sub_diary, sub_assistant, sub_unlimited (период 1 месяц; затем добавить годовые планы 1 год; цены как в блоке A).
  3. Покупки внутри приложения: pack_1h, pack_10h, pack_50h, pack_200h — тип Consumable; full_unlock — Non-Consumable.
  4. Пользователи и доступ → Sandbox → Testers: создать тестовый Apple ID (e-mail, пароль, страна).
  5. На iPhone: Настройки → App Store → Аккаунт песочницы → войти этим тестовым Apple ID (основной аккаунт не трогать).
  6. Напиши «готово» — я залью сборку в TestFlight и проверим покупку.
