# Настройка платежей в Google Play — Дикта (шаг за шагом)

Дата: 25.09.2026. Пакет: `com.dictapro.app`. Аккаунт: Albatech Group (ID 8038044048435052439).

## 1. Товары (подписки)

Консоль: **Монетизация → Продукты → Подписки → Создать подписку**.
На каждую подписку — **два базовых плана**: месячный и годовой (вкладка «Базовые планы»).

| ID подписки | Название | Базовый план «месяц» | Базовый план «год» | Бонус в приложении |
|---|---|---|---|---|
| `sub_24h` | Дневник | 490 ₽ | 4 900 ₽ | +12 ч в подарок каждый месяц |
| `sub_120h` | Ассистент | 990 ₽ | 9 900 ₽ | +60 ч в подарок каждый месяц |
| `sub_unlimited` | Безлимит | 1 990 ₽ | 17 910 ₽ | подарок-промокод на следующий продукт |

Цены для других стран (задать в консоли по странам):
- Узбекистан: 49 000 / 99 000 / 199 000 сум (год — ×10 / ×10 / ×9)
- Европа: 4,99 € / 9,99 € / 19,99 €
- США: $4,99 / $9,99 / $19,99

Идентификаторы базовых планов (Play требует свой ID на каждый план):
`monthly` и `yearly` (например, подписка `sub_24h` → планы `sub_24h-monthly`, `sub_24h-yearly`).

## 3. Лицензионные тестеры (чтобы проверять оплату без денег)
Консоль: **Настройки → Лицензионное тестирование** → добавить Google-аккаунты
(свой аккаунт и/или тестеров). Их покупки — **тестовые, деньги не списываются**,
подписка «действует» в ускоренном режиме (можно ускорить период в консоли).

## 4. Тестеры внутреннего трека
1. **Тестирование → Внутреннее тестирование → Тестировщики**: список с адресами
   (`hardominsk@gmail.com`, `annabatura@gmail.com`).
2. **В выпуске** отметить этот список галочкой → Сохранить.
   *Если выпуск править не даёт — создать новый выпуск (как выяснили на Рунах).*
3. Скопировать ссылку «Присоединиться в веб» / «на Android» и отправить тестерам.

## 5. Порядок проверки оплаты
1. Создать подписки (п.1) → дождаться статуса «Активно».
2. Добавить лицензионных тестеров (п.3).
3. Выпустить сборку с кодом оплаты (уже есть в 1.4.1) в внутренний трек.
4. На Android-телефоне (лицензионный тестер) открыть подписку → оформить → убедиться,
   что лимиты снялись/применились и что после перезапуска статус сохранился.
5. Проверить в авиарежиме: подписка подтверждена → работаем офлайн (льготный период 30 дней).
6. Для iPhone — отдельно: **App Store Connect → Подписки** (те же ID) + **Sandbox-аккаунты**.
