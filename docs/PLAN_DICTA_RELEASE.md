## 2. Чек-лист тестов перед релизом (оба раза — Android и iOS)

- запись 10 мин → расшифровка **офлайн** (авиарежим) → текст корректный;
- длинная запись (>5 ч): предупреждение + не падает; экран гаснет — расшифровка идёт;
- «Продолжить» после прерывания (карточка читается, работает);
- итоги **локальные** (авиарежим) и **онлайн** (сеть);
- экспорт TXT/PDF/HTML — файлы открываются, страницы нормального размера;
- переименование/удаление/теги/поиск;
- покупка: лицензионный тестер (Android) / Sandbox (iOS) → лимиты снимаются, статус сохраняется после перезапуска;
- офлайн после покупки: работает без сети;
- русский/английский интерфейс — без «смеси языков»;
- холодный старт в авиарежиме: не виснет, не падает.
