## Краткий ответ (TL;DR)

Для DictaPro оптимальная схема — **гибрид**: офлайн VOSK остаётся бесплатным мгновенным слоем, а кнопка «Точный транскрипт (онлайн)» ведёт на **Groq (`whisper-large-v3-turbo`, $0.04/час, регистрация по e-mail без телефона и карты, free tier 2000 аудио-запросов в день)** как основной маршрут и **Deepgram Nova-3 ($200 стартовых кредитов без карты, диаризация включена)** или **Mistral Voxtral Mini Transcribe V2 (русский из 13 языков, файлы до 3 часов, диаризация, $0.003/мин)** как запасной для тех, у кого есть телефон/карта. Саммари — **GLM-4.5-Flash через уже подключённый Z.ai (бесплатно, контекст 128K)** или Gemini 2.5 Flash-Lite (free tier, но нужен постоянный VPN и Google-аккаунт). Полная себестоимость часа «транскрипция + саммари» на рекомендуемом маршруте — **$0.04–0.12**, то есть пакеты часов с наценкой ×5–10 остаются высокомаржинальными. OpenAI, Google Cloud и Azure для пользователя из РФ без зарубежной карты практически недоступны; Yandex SpeechKit требует телефон и карту при регистрации биллинга и при этом показал худшую точность по-русски в независимом бенчмарке.

### 1.2. Заметки по ключевым провайдерам

**Groq.** Самый выгодный маршрут «цена/качество/доступность» для этого проекта. Платные тарифы: `whisper-large-v3-turbo` — $0.04/час при скорости ~216–228× realtime (час аудио обрабатывается за ~16 секунд), `whisper-large-v3` — $0.111/час при WER 10.3% против 12% у turbo в агрегированных метриках вендора ([GroqDocs](https://console.groq.com/docs/speech-to-text), [CloudZero](https://www.cloudzero.com/blog/groq-pricing/)). Free tier не требует карты и даёт 20 RPM и 2000 аудио-запросов в день на каждую whisper-модель, что при батчинге покрывает десятки часов аудио ежедневно; регистрация — по e-mail (или Google/GitHub), телефон не запрашивается ([Eesel](https://www.eesel.ai/blog/groq-pricing), [Unified.to](https://unified.to/blog/how_to_get_a_grok_xai_and_groq_api_key_and_connect_it_to_your_product)). Ограничения: файл до 25 МБ на free tier (100 МБ на dev), минимальный биллинг 10 секунд на запрос, лимиты действуют на организацию целиком, а не на ключ. Для диктофона с записями 5–60 минут это означает обязательное чанкование: часовая запись в MP3 64 кбит/с — это ~28 МБ, то есть даже по размеру файл желательно резать, а с учётом лимита 25 МБ — обязательно.

**Deepgram.** Nova-3 multilingual (русский входит именно в мультиязычный режим, «monolingual» — это английский) стоит $0.0052/мин для pre-recorded, диаризация спикеров в этом режиме включена без доплаты, чего нет почти ни у кого из конкурентов ([HappyRobot](https://www.happyrobot.ai/hub/deepgram-pricing), [Gladia](https://www.gladia.io/blog/deepgram-pricing)). Регистрация по e-mail/Google/GitHub, стартовые $200 кредитов без карты и без срока сгорания — это ~640 часов транскрипции, то есть фактически бесплатный запасной канал на годы для личного использования и на полноценное бета-тестирование фичи ([AICredits](https://aicredits.dev/submissions/89-deepgram-200-free-speech-api-credits)). По Habr-тесту качество русского среднее (44.9%), зато скорость 128.8× realtime и зрелый API.

**Mistral Voxtral.** Февральский Voxtral Mini Transcribe V2 — самый технологичный вариант для длинных записей: до 3 часов аудио в одном запросе (никакого чанкования), диаризация с метками времени, word-level timestamps, context biasing до 100 слов (для русского пока экспериментально), 13 языков, включая русский ([Mistral](https://mistral.ai/news/voxtral-transcribe-2/), [Mistral Docs](https://docs.mistral.ai/studio/audio/speech_to_text)). Цена $0.003/мин ($0.18/ч) ([HN](https://news.ycombinator.com/item?id=46886735)). Блокер именно для вашего сценария: free tier La Plateforme требует SMS-верификацию телефона, карта не нужна ([PricePerToken](https://pricepertoken.com/endpoints/mistral/free)). Если телефон когда-либо появится — это кандидат №1 для длинных файлов.

**ElevenLabs Scribe v2.** Лучшая точность русского в независимом тесте и разумная цена $0.22/час; регистрация по e-mail/Google/GitHub без карты, free-план даёт 10 000 кредитов в месяц из общего пула (для Scribe это порядка нескольких часов в месяц) ([ElevenLabs](https://elevenlabs.io/pricing/api), [Puter](https://developer.puter.com/tutorials/how-to-get-elevenlabs-api-key/)). Минус: кредиты общие с TTS и другими продуктами, free-план без коммерческой лицензии, а пополнение требует карты.

**AssemblyAI.** Universal-2 за $0.15/час — дешевле OpenAI при сопоставимом качестве русского (второе место в Habr-тесте); $50 стартовых кредитов без карты, кредиты не сгорают, диаризация +$0.02/ч ([AssemblyAI Models](https://www.assemblyai.com/docs/getting-started/models), [AssemblyAI Billing](https://www.assemblyai.com/docs/billing-and-pricing)). Хороший резерв после Deepgram.

**OpenAI / Google Cloud / Azure.** Все три для пользователя из РФ без зарубежной карты фактически закрыты. OpenAI блокирует регистрацию из России и по IP, и по телефону ([BankInfoSecurity](https://www.bankinfosecurity.com/openai-drops-chatgpt-access-for-users-in-china-russia-iran-a-25631)); API требует prepaid-оплату картой. Google Cloud STT v2 дорог ($0.96/ч стандарт) и требует полноценного облачного биллинга; единственный разумный режим — dynamic batch ~$0.24/ч ([BrassTranscripts](https://brasstranscripts.com/blog/google-cloud-speech-to-text-pricing-2025-gcp-integration-costs)). Azure batch за $0.18/ч с включённой диаризацией объективно неплох, но нужен Azure-аккаунт с подпиской и картой ([Azure](https://azure.microsoft.com/en-us/pricing/details/speech/)). Эти трое имеет смысл держать в списке «на будущее» для международных пользователей приложения, но не для вашего сценария.

**Yandex SpeechKit.** Единственный провайдер, который работает из РФ без VPN и принимает рубли, с очень дешёвым отложенным режимом (~9 ₽/час) и лимитом асинхронных файлов до 4 часов ([Pimenov](https://pimenov.ai/knowledge/yandex-speechkit-sintez-raspoznavanie-rechi/)). Для конечных пользователей из РФ, у которых есть карта, — рабочий вариант «без VPN», поэтому его стоит оставить как опцию BYOK (bring your own key) в приложении.

## 2. Офлайн против облака: честное сравнение

Текущий офлайн-стек DictaPro (VOSK small) имеет предсказуемый потолок. Даже **большая** русская модель `vosk-model-ru-0.42` (1.8 ГБ) по официальным данным Alpha Cephei даёт WER 4.4–4.5% на аудиокнигах, но 17.9% на записях устройств SOVA, 19.5% на YouTube и **36% на телефонных звонках** ([Alpha Cephei](https://alphacephei.com/vosk/models)). Малая модель, которая реально помещается в мобильное приложение, заметно слабее большой. То есть разрыв «VOSK small vs облачный Whisper large-v3» на реальной диктовке — это не проценты, а разы: у Whisper large-v3 по-русски типичный real-world WER оценивается в 8–14% ([VexaScribe](https://vexascribe.com/how-accurate-is-whisper)), а turbo-вариант теряет к large-v3 лишь 2–4 п.п. на Tier-2 языках, куда относится русский ([NovaScribe](https://novascribe.ai/whisper-large-v3-vs-turbo)).

Реалистичность офлайн-Whisper на среднем Android подтверждается бенчмарками whisper.cpp на ARM: на 8-ядерном RK3588 (уровень среднего мобильного SoC) модель small (466 МБ, ~0.9 ГБ RAM) работает с RTF ~0.47 — то есть примерно в 2 раза быстрее реального времени, а medium (1.5 ГБ, >2 ГБ RAM) уже медленнее реального времени (RTF 1.51) ([Turing Pi](https://turingpi.com/whisper-cpp-piper-tts-arm64-turing-pi-rk3588/)). Практический вывод для DictaPro: **whisper.cpp small / base как скачиваемая опция «улучшенный офлайн» реалистичен** для фоновой пост-обработки (часовая запись обработается за ~30 минут в фоне), но не для транскрипции «на лету»; large/turbo на телефоне нереалистичны (3–4 ГБ RAM и долгая работа). Мультиязычный WER small оценивается в ~7% против ~3.5% у large-v3 ([OpenWhispr](https://openwhispr.com/blog/whisper-model-sizes-explained)) — то есть даже офлайн-small заметно точнее VOSK, и это хороший бесплатный апгрейд базового слоя без каких-либо регистраций вообще. Компромиссный путь: оставить VOSK small для мгновенного превью во время записи, а whisper.cpp small предлагать как «офлайн-улучшение» по кнопке.

## 3. ИИ-саммари: как это делают лидеры и сколько это стоит

### 3.1. Подходы продуктов

Успешные сервисы строят саммари не как «пересказ», а как **структурированный протокол**. Fireflies генерирует «Super Summaries» с отдельными секциями — обзор, action items, аутлайн, ключевые слова — и позволяет задать собственный промпт-шаблон один раз для всех встреч; именно структура, а не голый текст, оказывается тем, что пользователи реально читают ([JustTalkingTech](https://justtalkingtech.medium.com/otter-vs-fireflies-in-2026-the-veterans-reviewed-1ae7a9409eaa)). Otter делает ставку на ролевые шаблоны (продажи: возражения, боли, следующие шаги; рекрутинг: сильные стороны кандидата) и AI-чат по транскрипту ([Grain](https://grain.com/blog/fireflies-vs-otter)). Granola использует гибрид: пользователь помечает 2–3 триггера по ходу встречи, а ИИ «усиливает» эти заметки транскриптом после её конца ([Granola](https://www.granola.ai/blog/how-to-take-good-meeting-notes-ai)). Общий знаменатель: фиксированные секции, явное извлечение решений/задач/владельцев/дат и ссылки пунктов саммари на таймкоды транскрипта.

Для длинных записей стандарт индустрии — **map-reduce**: транскрипт режется на сегменты по ~15 минут, каждый саммаризируется отдельно структурированным промптом (сущности, решения, даты, риски), затем промежуточные результаты сводятся финальным промптом; при переполнении — иерархическая редукция ([AssemblyAI](https://www.assemblyai.com/blog/summarize-meetings-llms-python), [F22 Labs](https://www.f22labs.com/blogs/map-reduce-for-large-document-summarization-with-llms/)). Для DictaPro с контекстом GLM-4.5-Flash 128K часовая запись (~10k слов ≈ 13–20k токенов русского текста) помещается целиком **без map-reduce** — упрощение архитектуры и отсутствие потерь на стыках; map-reduce понадобится только для записей 4+ часов.

## 4. Специфика Z.ai (bigmodel)

У Z.ai действительно появился ASR-API: **GLM-ASR-2512** (декабрь 2025) — endpoint `https://api.z.ai/api/paas/v4/audio/transcriptions`, цена $0.03 за 1M токенов, что в документации пересчитано как ≈$0.0024/минуту (~$0.14/час) ([UsagePricing](https://www.usagepricing.com/blueprint/zhipu-ai), [Puter](https://developer.puter.com/tutorials/zai-glm-api-pricing/)). Модель заявляет CER 0.0717, hotwords (до 100 словарных слов) и передачу предыдущего контекста через `prompt` ([Z.ai API](https://docs.z.ai/api-reference/audio/audio-transcriptions)). **Два жёстких ограничения**: (1) максимум 30 секунд аудио и 25 МБ на запрос — часовая запись превращается в 120 последовательных запросов; (2) русский язык **не заявлен** — официально «китайский + диалекты, английский, десятки мировых языков (фр., нем., яп., кор., исп., араб. и др.)» без русского в перечне, а в обзорной таблице Z.ai для GLM-ASR указано «English & Chinese» ([Z.ai Docs](https://docs.z.ai/guides/audio/glm-asr-2512), [Z.ai Overview](https://docs.z.ai/guides/overview/overview)). Открытая версия GLM-ASR-Nano-2512 прямо рекомендует для широкой мультиязычности использовать Whisper ([Dev.to](https://dev.to/czmilo/glm-asr-nano-2512-the-complete-2025-guide-to-zais-open-source-speech-recognition-model-25b1)).

Практический вывод: GLM-ASR-2512 годится как **аварийный третий маршрут** (баланс уже есть, API уже интегрирован), но требует чанкования по 25–30 с с передачей хвоста предыдущего чанка в `prompt` для связности, даёт ~120 запросов на час (~$0.14 — цена приемлемая, но ошибки на границах слов неизбежны) и качество по-русски непредсказуемо. Тестировать на своих записях до включения в релиз. А вот **GLM-4.5-Flash для саммари — безусловно подходит**: бесплатен, контекст 128K токенов, max output 96K, режим thinking/non-thinking переключается параметром ([Z.ai GLM-4.5](https://docs.z.ai/guides/llm/glm-4.5)) — часовые транскрипты проходят целиком, и ваши $13 баланса на саммари не тратятся вообще.

## 5. Рекомендуемая гибридная архитектура

Схема: **VOSK small (мгновенно, бесплатно, офлайн) → кнопка «Улучшить офлайн» (whisper.cpp small, скачиваемая модель ~466 МБ) → кнопка «Точный транскрипт (онлайн)» (BYOK: Groq / Deepgram / Mistral / …) → «Саммари» (Z.ai GLM-4.5-Flash по умолчанию)**. Технические решения для онлайн-слоя:

- **Чанкование**: резать аудио по границам пауз (VAD уже есть в стеке) на куски 5–10 минут для Groq/Deepgram; для GLM-ASR — 25 с с overlap 1–2 с и передачей хвоста в `prompt`; конвертировать в MP3/Opus 64 кбит/с моно 16 кГц — час ≈ 28 МБ (MP3) или ~14 МБ (Opus), что снимает лимит размера почти у всех.
- **Надёжность**: экспоненциальный backoff с джиттером на 429/5xx; идемпотентные повторы чанков; чекпоинт прогресса после каждого чанка, чтобы прерванная транскрипция часа не начиналась с нуля; очередь с 1–2 параллельными чанками (упирается в RPM free tier).
- **Прогресс**: «чанк i/N + секунды обработано», оценка оставшегося времени из RTF провайдера (Groq ~200× realtime — час ≈ 20–30 с с учётом загрузки; Deepgram ~129×).
- **Ключи**: как сейчас для Z.ai — SharedPreferences/Keystore, ключ никогда не покидает устройство, запросы идут напрямую провайдеру (никакого своего бэкенда = ноль серверных расходов и простая политика приватности).
- **Приватность**: явный диалог «аудио будет отправлено на серверы {провайдер} ({страна})»; у Groq/Deepgram/ElevenLabs серверы в США/EU, у Z.ai — Сингапур/Китай; у Gemini free tier данные могут использоваться для обучения — это нужно честно показывать в UI ([AIFreeAPI](https://www.aifreeapi.com/en/posts/gemini-api-free-tier-complete-guide)).

Расходы при профиле «10 записей в неделю по 30 минут» (~21.7 ч/мес): маршрут «Бюджет» (Groq turbo + GLM-4.5-Flash) — **$0.87/мес**, «Баланс» (Groq large-v3 + GLM-4.5-Air) — **$2.50/мес**, «Качество» (Scribe v2) — $4.81/мес, «Максимум» (Deepgram + GPT-4o-mini) — $6.82/мес. На free tier Groq (2000 аудио-запросов/день) такой профиль при разумном чанковании фактически бесплатен.

### G.2. Ранжированный список «что реально доступно без телефона и карты»

1. **Groq free tier** — транскрипция: 2000 аудио-запросов/день бесплатно, час аудио ≈ 6–12 запросов при чанковании → фактически неограниченно для личного использования; качество русского хорошее; VPN нужен. **Час = $0.00.**
2. **Z.ai GLM-4.5-Flash** — саммари: бесплатно, контекст 128K, аккаунт уже есть. **Час саммари = $0.00.**
3. **Deepgram $200** — ~640 часов транскрипции с диаризацией на годы вперёд. **Час = $0.00 пока живут кредиты.**
4. **AssemblyAI $50** — ~330 часов. **Час = $0.00 пока живут кредиты.**
5. **ElevenLabs free** — несколько часов в месяц лучшего по-русски качества.
6. **Gemini free tier (с постоянным VPN)** — аудио до 9.5 часов на запрос (!), можно вообще без чанкования: Gemini «слушает» файл целиком и сразу пишет транскрипт+саммари; 250 RPD на 2.5 Flash хватает с запасом ([Google AI](https://ai.google.dev/gemini-api/docs/audio)). Минусы: VPN обязателен на каждый запрос, данные идут на обучение, пунктуация/таймкоды слабее специализированного ASR.
7. **Fireworks $1** — ~11–18 часов large-v3 за доллар.

Комбинация пунктов 1+2 закрывает сценарий «точная транскрипция + саммари» **полностью бесплатно и без единой регистрации с телефоном** — это и есть рекомендуемый дефолт для онлайн-кнопки DictaPro.

### G.3. GLM-ASR как запасной путь: подводные камни чанкования

Часовая запись через GLM-ASR-2512 = ~120 запросов по 30 с. Проблемы: (1) обрыв слов на границах — смягчается overlap 1–2 с и склейкой по общей подстроке; (2) потеря контекста — частично компенсируется параметром `prompt` (хвост предыдущего чанка, до 8000 символов) ([Z.ai API](https://docs.z.ai/api-reference/audio/audio-transcriptions)); (3) пунктуация и регистр на стыках деградируют; (4) 120 запросов при неофициальном лимите ~60 RPM — минимум ~2–4 минуты ожидания; (5) русский не заявлен — качество лотерея. Стоимость при этом привлекательная: ~$0.14/час. Рекомендация: реализовать как третий маршрут «когда ничего другое не доступно», обязательно прогнав 3–5 своих русских записей перед решением.

### G.4. Офлайн whisper.cpp — без регистрации вообще

Для полноты: единственный путь без аккаунтов — whisper.cpp small на устройстве (скачиваемая GGML-модель ~466 МБ, ~0.9 ГБ RAM, ~0.5× realtime на среднем ARM) ([Turing Pi](https://turingpi.com/whisper-cpp-piper-tts-arm64-turing-pi-rk3588/), [OpenWhispr](https://openwhispr.com/blog/whisper-model-sizes-explained)). Часовая запись обработается фоново за ~30–60 минут, качество по-русски ощутимо выше VOSK small. Это бесплатный «средний» слой между VOSK и облаком и сильный аргумент продажи Pro-версии.

## 6. Риски

- **Рост цен / отмена free tier.** Groq держит цены стабильно с 2024, но free tier — маркетинговый продукт; Z.ai прямо предупреждает, что бесплатность Flash «может измениться без уведомления» ([Layer3Labs](https://www.layer3labs.io/guides/z-ai-pricing)). Митигация: абстракция провайдеров (единый интерфейс STT/LLM), конфиг смены маршрута без обновления приложения (remote config), минимум 3 поддерживаемых провайдера.
- **Геоблокировки.** OpenAI уже закрыт; Google режет квоты free tier (апрель 2026: −50–80%) ([Metacto](https://www.metacto.com/blogs/the-true-cost-of-google-gemini-a-guide-to-api-pricing-and-integration)); любой из западных провайдеров может ввести региональные ограничения. BYOK-модель переносит этот риск на ключ пользователя, а не на приложение — но поддерживать стоит и российский вариант (Yandex SpeechKit BYOK) для тех, у кого нет VPN.
- **Приватность аудио.** Записи встреч уходят на серверы: Groq/Deepgram/ElevenLabs/Mistral — США/EU; Z.ai — Сингапур/Китай; Yandex — РФ (152-ФЗ-совместимо); Gemini free tier может использовать данные для обучения. В UI обязателен явный выбор провайдера с пояснением, чьи серверы, и офлайн-режим по умолчанию как приватный дефолт.
- **Качество русского у китайских ASR.** GLM-ASR русский не заявлен; SenseVoice и подобные оптимизированы под CJK ([WhisperNotes](https://whispernotes.app/blog/sensevoice-fastest-cjk-transcription)) — не строить на них основной маршрут для русского без собственного теста.
- **Монетизация в РФ.** Биллинг Google Play для РФ заморожен; выручка с РФ-аудитории возможна через RuStore (15%) или внешние платежи — закладывать в план две платёжные схемы с самого начала ([DTF](https://dtf.ru/howto/5283861-oplata-google-play-v-rossii-sposoby-i-rekomendatsii)).

## 7. Итоговые рекомендации

1. **STT онлайн — топ-2: Groq (`whisper-large-v3-turbo` дефолт, `whisper-large-v3` «максимальное качество») + Deepgram Nova-3 как запасной** (диаризация включена, $200 кредитов без карты). 1 час = **$0.04 / $0.11 / $0.31** соответственно. Третий резерв — Mistral Voxtral (для пользователей с телефоном) и GLM-ASR-2512 (когда есть только Z.ai).
2. **Саммари — Z.ai GLM-4.5-Flash (бесплатно, 128K контекст, у вас уже интегрирован)**, запасной — Gemini 2.5 Flash-Lite. Часовые записи саммаризировать целиком, без map-reduce; промпт — структура из раздела 3.2.
3. **Офлайн-апгрейд: добавить whisper.cpp small как скачиваемый «улучшенный офлайн»** — закрывает разрыв качества без сети и усиливает Pro-версию.
4. **Монетизация: freemium → Pro разово $6.99–9.99 + BYOK-онлайн без своей платёжки; для РФ — RuStore/внешняя оплата.** Опциональные пакеты часов $0.99/$3.99/$11.99 с наценкой ×3–5 дают маржу 38–86%. Безубыточность $5000 — ~840 покупок по $6.99.
5. **При 10 записях/неделю по 30 минут** рекомендуемый маршрут обходится пользователю в $0 (free tier Groq + Z.ai) — мощный маркетинговый аргумент: «платите один раз за приложение, а не каждый месяц за транскрипцию».
