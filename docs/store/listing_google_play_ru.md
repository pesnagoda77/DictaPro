# ДиктаПро — листинг Google Play (RU)

## Название (≤30 символов)
ДиктаПро — диктофон с расшифровкой

## Короткое описание (≤80 символов)
Диктофон, который сам пишет текст: офлайн-расшифровка речи на русском

## Полное описание (≤4000 символов)
ДиктаПро — диктофон нового поколения. Он не просто записывает звук — он превращает речь в текст, пока вы говорите. Вся расшифровка работает прямо на телефоне: без интернета, без отправки файлов на чужие серверы, без подписок для базовых функций.

КОМУ ПРИГОДИТСЯ
— Врачам, юристам, журналистам: запись консультации → готовый текст через минуты
— Студентам: лекция превращается в конспект с таймкодами
— Бизнесу: протоколы встреч и переговоров без машинистки
— Всем, кто диктует заметки, письма и идеи на ходу

ГЛАВНОЕ
• Офлайн-расшифровка на устройстве. Точная модель GigaAM работает локально — файлы никуда не уходят
• Запись в фоне и при выключенном экране
• Длинные записи: расшифровка не боится часовых аудио, обрыв продолжится с того же места
• Поиск по тексту всех записей — найдите нужное место по слову
• Экспорт в TXT, HTML и PDF с таймкодами
• Термины под запись: имена и аббревиатуры распознаются точнее
• Светлая и тёмная тема

ПРИВАТНОСТЬ
Записи, тексты и ключи хранятся только на вашем устройстве. Онлайн-расшифровка (опционально, по желанию) — через защищённый сервер, только с вашего явного согласия.

ПОДПИСКА «ИИ-итоги»
Базовые функции бесплатны и без рекламы. Подписка открывает ИИ-итоги записей: краткое содержание, ключевые пункты, список решений — считается на сервере за ИИ-часы (1 час = 1 час аудио).

Технические требования: Android 8.0+, 300 МБ свободного места (модель распознавания скачивается один раз).
