## ⛔ ПРОБЛЕМА, ИЗ-ЗА КОТОРОЙ ДЕЛАЕТСЯ БЭКАП
- Приложение на айфоне **не открывается без интернета**.
- Причина: iOS при первом запуске приложения с development/ad-hoc-подписью показывает «Не удалось проверить приложение. Для проверки требуется подключение к интернету» — система онлайн проверяет сертификат разработчика. Это НЕ баг нашего приложения.
- **Славан не может подключить айфон к интернету**: в Mail есть сообщения, которые при синхронизации (IMAP/аккаунты) могут исчезнуть.
- **Поэтому и нужен БЭКАП АЙФОНА (локальный, по кабелю, БЕЗ интернета)** — чтобы защитить данные телефона, прежде чем выпускать его в сеть. Бэкап по кабелю не запускает синхронизацию и сохраняет текущие локальные данные (включая Mail).

## План разблокировки (по порядку)
1. **Подключить айфон кабелем** → сделать локальный бэкап телефона (`pymobiledevice3` backup; интернет НЕ нужен, синхронизация не запускается).
2. Затем кратко впустить айфон в сеть → открыть DictaPro (iOS проверит сертификат) → приложение запустится.
   - Опция безопасности: перед этим временно отключить Fetch New Data для почты (Настройки → Почта → Загрузка новых данных → Вручную), потом вернуть как было.
   - Если после синхронизации какие-то письма исчезнут — они есть в локальном бэкапе.
3. **Движок**: GigaAM v3 (sherpa_onnx) — модель ВЛОЖЕНА в сборку, сетевых загрузок нет. Проверить, что в iOS-сборке модель на месте (asset pack/flutter assets) — если нет, включить копирование в CI.
4. Альтернативы (если онлайн-проверка сертификата критична): включить **Developer Mode** на айфоне (iOS 16+: Настройки → Конфиденциальность и безопасность → Режим разработчика → вкл + перезагрузка) + доверие профилю (Настройки → Основные → VPN и управление устройством).
