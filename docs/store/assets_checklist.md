# Графические ассеты — чек-лист

## Иконка приложения (оба стора)
- Размер: 1024×1024 px, PNG
- Без прозрачности (App Store отклоняет с альфа-каналом)
- Резервируемость: значимые элементы в пределах 66% кадра (безопасная зона)
- Источник: адаптировать существующую иконку Дикты (D:\Projects\Releases\dictapro_v6\ или исходники в проекте)
- Форматы для Play: 512×512 (консоль) + 1024×1024 (если нужно). Для App Store: 1024×1024

## Feature Graphic (только Google Play)
- 1024×500 px, PNG/JPEG
- Без текста мелкого кегля, без скриншотов интерфейса в центре
- Допускается: логотип + короткий слоган («Говорите — мы пишем»)
- Показывается в шапке страницы приложения

## Требования сторов — сводка

### Google Play Console заполняем:
- Название приложения (≤30) — из listing_google_play_ru/en.md
- Короткое описание (≤80)
- Полное описание (≤4000)
- Иконка 512×512
- Feature Graphic 1024×500
- Скриншоты (мин 2)
- Категория: Производительность
- Контент-рейтинг: пройти анкету IARC (ответы: нет сбора данных, нет UGC → Everyone)
- Email разработчика + сайт (опц.)
- Политика конфиденциальности: URL (privacy_policy.md → выложить на sites.google.com как для CoffeeFortune)
- Цена: бесплатно + подписка ИИ-итогов (продукты уже должны быть созданы)
- Объявление приложения (ads): нет
- Целевая аудитория: все возрасты

### App Store Connect заполняем:
- Название (≤30), субтитр (≤30), промо-текст (≤170), описание (≤4000) — из listing_appstore.md
- Keywords (≤100 символов, через запятую)
- Иконка 1024×1024 (без альфы)
- Скриншоты 6.7" (1290×2796) мин 3 + 6.5" (1242×2688) мин 3
- Категория: Productivity
- Возраст: 4+
- Политика конфиденциальности: URL + текст в анкете приватности (App Store требует заполнить Nutrition Label: «данные не собираются»)
- Покупки: подписка ИИ-итогов (auto-renewable) — продукт должен быть создан
- Review notes: объяснить, что онлайн-функции требуют подписку + ключ
