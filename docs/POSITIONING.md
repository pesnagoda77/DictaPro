# ПОЗИЦИОНИРОВАНИЕ DictaPro — «Privacy-first офлайн-диктофон»

Дата: 14.09.2026 · Автор: Claude по идее Славана

## Главный тезис (для стора и рекламы)
> **Ваши голосовые данные — только ваши.**
> Запись, расшифровка, саммари и поиск работают ПРЯМО НА ТЕЛЕФОНЕ. Без облака,
> без аккаунта, без слежки. В эпоху, когда всё уходит в серверы, приватность — это премиум.

## За что платит пользователь (четко и честно)
| Что | Почему за это платят |
|---|---|
| **Полный офлайн** | Данные не покидают устройство. Работает в самолёте, на даче, в суде, где нет сети. Никакой телеметрии |
| **Профессиональный инструмент** | Запись (включая фоном с выключенным экраном), импорт любых форматов, редактор, теги, поиск, экспорт TXT/MD/SRT/PDF |
| **Локальная расшифровка** | Распознавание на устройстве (без интернета), локальная чистка текста (числа, пунктуация), без лимитов по минутам |
| **Никаких обязательных подписок** | Разовая покупка = приложение навсегда (в отличие от облачных сервисов с помесячной оплатой) |
| **Осознанный выбор** | Хочешь максимальную точность — можешь ДОБРОВОЛЬНО подключить облако (свой ключ, с предупреждением). Хочешь полную приватность — ничего не подключаешь и платишь только за приложение |

## Почему это выигрышная стратегия глобально
1. **Тренд на приватность растёт** с распространением ИИ: люди не хотят отдавать голос/встречи в чужие серверы (Adobe/OpenAI-скандалы, регуляторика GDPR/152-ФЗ).
2. **Облачные диктофоны дороги и требуют аккаунтов** — офлайн-конкурентов почти нет (Just Press Record — единственный заметный, но слабый по функциям).
3. **Наш зонтик «офлайн = приватно = ваше»** отличает продукт от массы «AI-транскрибаторов» и защищает от ценовых войн (мы не платим за облако — маржа выше).
4. **Глобальность**: приватность не знает языков — приложение с этой идеей продаётся в любой стране, где люди платят за инструменты.

## Как коммуницируем (транспарентность)
- **В приложении**: постоянная мелкая пометка «Обработка на устройстве»; перед любой сетевой операцией — явное «Вы выходите из офлайн-режима» (ничего незаметного).
- **В сторе (описание)**: первым абзацем — «Данные остаются на устройстве. Без аккаунта. Без облака.»; отдельным блоком — «Дополнительно (по желанию): облачная расшифровка и саммари со своим ключом».
- **В цене**: разовая покупка = вся офлайн-функциональность; опциональные онлайн-пакеты — отдельно и прозрачно.

## Что нельзя делать (антипаттерны, за которые теряют доверие)
- ❌ Заявлять «офлайн», а тихо отправлять данные в облако (саммари в v43 было таким — исправляем).
- ❌ Прятать передачу данных в мелком шрифте.
- ❌ Обязывать к аккаунту/подписке там, где можно без них.

## Следствие для релиза
Первый релиз DictaPro в сторах = **офлайн-приложение с сильным набором функций**, а онлайн-слой —
явная опция для тех, кому нужен максимум точности. Маркетинг начинать с приватности, не с «AI».
