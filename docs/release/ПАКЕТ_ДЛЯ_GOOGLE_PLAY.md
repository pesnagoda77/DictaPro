# Пакет для Google Play — ДиктаПро (черновик, 16.09.2026)

## 1. Карточка приложения

**Название (до 30 знаков):** `ДиктаПро — офлайн-диктофон` (26)

**Короткое описание (до 80 знаков):** `Запись и расшифровка речи без интернета. Всё считается на телефоне.` (67)

**Полное описание (до 4000 знаков):**

> ДиктаПро — диктофон, который сам превращает речь в читаемый текст. Расшифровка работает **на самом телефоне**: запись не уходит в интернет, аккаунт не нужен, подписки нет.
>
> Что умеет:
> • Запись в один тап, таймер и сценарии: диктовка, лекция, шумное помещение.
> • Расшифровка на устройстве: пунктуация, заглавные буквы, числа цифрами.
> • Понятная точность: обычная речь — почти без ошибок, техническая — с редкими оговорками.
> • Редактор диалога: разделение по говорящим, правка реплик, смена говорящего.
> • Прослушивание с ускорением и переход к нужному месту по тексту.
> • Сводка по записи: коротко о главном.
> • Теги и поиск по всем записям.
> • Экспорт: HTML, PDF, текст — с таймкодами или без.
> • Термины записи: подсказка для редких слов, латиницы и аббревиатур.
>
> Почему офлайн: приватность. Расшифровка, поиск и сводка считаются на устройстве, поэтому запись не покидает телефон. Если вам удобнее облако (например, для более точной расшифровки или сводки), его можно включить отдельно — по умолчанию он выключен.
> • Никакой рекламы.
> • Никакой подписки: покупка один раз.
>
> Кому подходит: тем, кто диктует и ведёт записи по работе — юристам, врачам, преподавателям и студентам, аграриям, журналистам; всем, кому важны и текст, и приватность.

**Категория:** Инструменты (Tools). Дополнительно: «Продуктивность» — как альтернатива.
**Контакт:** `<почта поддержки>` — указать перед подачей.
**Политика конфиденциальности:** ссылка на опубликованную страницу (файл `privacy/index.html` в этом же каталоге).

**Ключевые слова для поиска (указываются в текстах, не отдельным полем):**
диктофон, расшифровка, транскрибация, запись лекций, диктовка, офлайн, без интернета, приватность, без подписки, запись совещаний, текст из записи.

## 2. Безопасность данных (форма Data safety)

| Вопрос Play | Ответ |
|---|---|
| Собирает ли приложение данные? | **Нет** (по умолчанию ничего не передаётся) |
| Передаются ли данные третьим лицам? | **Нет** — если пользователь сам не включит облачные функции |
| Данные передаются в зашифрованном виде? | Да (HTTPS), если пользователь включил облачную функцию |
| Можно запросить удаление данных? | Нечего удалять: данные остаются у пользователя на устройстве |
| Типы данных (если облако включено пользователем) | «Другой контент, созданный пользователем» (текст записи) — только по инициативе пользователя, для функции приложения, без рекламы |

Формулировка для пояснения в форме: «Расшифровка, поиск и сводка выполняются на устройстве. Облачная расшифровка и облачная сводка выключены по умолчанию и включаются только самим пользователем; при включении текст записи передаётся выбранному пользователем сервису по защищённому соединению».

## 3. Разрешения и декларации

- **RECORD_AUDIO** — «Запись звука по нажатию кнопки записи. Аудио обрабатывается на устройстве». Обязательно указать, что запись начинается только по действию пользователя.
- **Микрофон в фоне** — не нужен: запись идёт при открытом приложении (в текущей версии). Формулировку про фон не заявляем.
- **Реклама** — отсутствует.
- **Рекламный идентификатор** — не используется.
- **Возрастной рейтинг** — 3+ (нет контента для взрослых, нет покупок внутри приложения с азартными механиками).
- **Целевая аудитория** — 18+ или 13+ на выбор; рекомендую **18+**, чтобы не попадать под детские политики и не проходить дополнительные проверки.
- **Доступ к файлам** — приложение сохраняет записи во внутреннюю папку; при экспорте используется системный выбор места.

## 4. Иконка и графика

- **Иконка приложения:** 512×512 PNG (без прозрачности), рисуем в стиле дизайн-системы: тёмная база `#12141a`, акцент янтарь `#e0a03c`.
- **Feature graphic:** 1024×500 PNG: слева название крупно, справа — фрагмент интерфейса на телефоне; фон — базовая тёмная, без текста по краям (Play обрезает).
- **Промо-видео:** не требуется.

## 6. Что нужно перед подачей (чек-лист)

1. Внедрить новое оформление в приложение (отдельная задача) — иначе скриншоты будут от старого интерфейса.
2. Вложить модель в сборку (задача 019) и собрать **AAB**.
3. Опубликовать политику конфиденциальности по ссылке (готовый файл `privacy/index.html`).
4. Заполнить формы: безопасность данных, рейтинг контента, декларация микрофона, целевая аудитория.
5. Подготовить иконку 512×512 и feature graphic 1024×500.
6. Снять скриншоты по плану и добавить подписи.
7. Проверить размер установки и честно указать в описании: «модель внутри, интернет не нужен».
8. Зарегистрировать приложение в Play Console до **30.09.2026** (общий дедлайн регистрации).
9. Решить канал оплаты (RuStore — от юрлица/ИП; Google Play в РФ платежи не проводит).

## 7. Политика конфиденциальности (краткая версия для карточки)

ДиктаПро не собирает персональные данные. Записи, расшифровки и сводки создаются и хранятся на вашем устройстве. Приложение не требует аккаунта и не использует рекламные идентификаторы. Облачная расшифровка и облачная сводка выключены по умолчанию; они включаются только по вашему решению, и в этом случае текст записи передаётся выбранному вами сервису по защищённому соединению. Удаление записей и всех данных выполняется средствами приложения или системы.
